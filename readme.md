# 文件说明：
- auto_install.py：自动检测并安装需要的模块。使用中科大镜像源。
- index.html：查询物品页面。也是网页的首页。
- main.py：程序主文件。
- items_cache.json：程序自动获取的物品名称列表。
- cache文件夹：
  - query_history.json：查询历史记录。
  - scene_xxx.json：场景缓存文件。每个场景对应一个文件。
- build_exe.bat：打包脚本，双击运行，可执行文件在dist文件夹下wmQuery.exe。每次更新重跑脚本即可。（打包脚本可能有问题，不想管了）

# 使用方式
1. 程序会生成json文件和cache文件夹，最好放在独立的文件夹下运行。
2. 运行程序后，浏览器打开网址http://127.0.0.1:8899。程序运行期间，命令行窗口不能关闭。

# 功能说明
- 查询时mod默认为0级，赋能默认为满级。不可修改。
- 自动补全物品名称。程序会自动获取物品名称列表并持久化，24小时内重复获取不会更新列表。
- 查询历史记录。历史记录最多记录10条数据。
- 场景功能。侧边栏可新增、删除场景。鼠标长按侧边栏的场景按钮后可上下拖动场景顺序。
  - 最上面的场景名称可以直接单击修改，并同步到侧边栏。
  - 名称有自动补全功能。
  - 掉率可接受两种格式：0.2和20%，计算时无区别。格式错误，则底色变红，计算时该行取0。
  - 输入自定义价格后，wm查询价格变为只读。
  - wm查询价格为状态为“游戏内”的最低3个价格的平均值。若查询到的价格数量少于3个或者没有查询到对应名称的价格，则显示对应文本，计算时价格为0。赋能为单个赋能的价格。
  - 最终价格首选为自定义价格，自定义价格为空再取wm查询价格。
  - 收益计算的公式为掉率*最终价格的总和。
  - 更新数据会查询没有自定义价格的物品价格。查询频率控制在1秒3次查询以内。
