# 文件说明：
- auto_install.py：自动检测并安装需要的模块。使用中科大镜像源。
- main.py：程序主文件。
- index.html：查询页面。也是网页的首页。
- items_cache.json：物品名称列表缓存。程序启动时只读取该文件，不联网；由物品查询页的「更新数据」按钮手动拉取生成。
- relic文件夹：
  - Void Relic_ByRelic - WARFRAME Wiki.html：官方wiki ByRelic 页面存档（浏览器 Ctrl+S 手动保存后放进来），未入库遗物查询的数据源。
- cache文件夹：
  - query_history.json：查询历史记录列表。
  - scene_xxx.json：场景缓存文件。每个场景对应一个文件。
  - relics_cache.json：未入库遗物的解析结果缓存。

# 使用方式
1. 运行程序后会自动打开浏览器，默认地址 http://127.0.0.1:8899；端口被占用时自动改用空闲端口，实际地址以程序窗口打印的为准。
2. 首次使用（没有物品缓存）时，在物品查询页点「更新数据」从 Warframe Market 拉取物品列表。

# 功能说明

## 物品查询
- 自动补全物品名称。数据源为本地物品缓存（items_cache.json），列表更新由页面「更新数据」按钮手动触发，平时启动零联网。
- 查询结果为游戏中玩家在售的最低价前 3 个卖单，表格上方同时显示近三天成交中间价统计（UTC日期，取自wm成交记录）。
- 查询历史记录，最多保留 10 条，点击可重查。

## 查询场景
- 场景管理：侧边栏可新增、删除场景；顶部场景名点击可直接修改（重命名后同步侧边栏和 json 文件名）；鼠标长按侧边栏的场景按钮后可上下拖动排序。
- 表格列：名称、掉率、声望、自定义价格、wm查询价格、期望价格、白金/十万声望。
- 名称列支持物品名自动补全（数据源与查询框相同），并做重复检测：与其他行重名时取消本次输入并提示。
- 名称列支持多行粘贴「名称 掉率」文本（如从 Wiki 复制的掉落表），自动逐行填充，行数不够时自动新增；与其他行重名的物品自动跳过。
- 掉率接受两种格式：24.78% 和 0.2478（同一数值），其他格式红底报错。
- 场景数据（表格行、上次查询时间、单局时间、掉落倍率）自动持久化到 cache/scene_xxx.json，重新打开不丢失。
- 「更新数据」按钮：逐行查询物品价格，自定义价格有值的行跳过，按钮上显示进度（如 查询中... 3/13）；当天（自然日）已更新过时会先弹窗确认。查询间隔约 400ms，符合 wm 1 秒至多 3 次的限速要求。
- wm查询价格列分两行显示：
  - 第一行（蓝色）：近三天成交中间价统计，格式为 三天均价（昨天/前天/大前天）；某天无成交显示「数据缺失」，任一天缺失则三天均价按「数据缺失」处理（计算取 0）。
  - 第二行：挂单价 d（d1/d2/d3），d 为最低 3 个卖单的均价。
  - 物品不存在显示「物品不存在」，在售数据不足 3 条显示「在售数据过少」，网络失败显示「查询失败」（前两者按 0 计算）。
- 联动计算：
  - 期望价格 = 掉率 × 价格。价格取自定义价格（优先），为空时取三天成交中间价的平均值。
  - 白金/十万声望 = 价格（不含掉率）÷ 声望 × 100000；声望留空则该行不计算，填了非正数或非数字红底报错。
  - 自定义价格有值时 wm 查询价格列置灰但保留内容，自定义价格金色边框；自定义价格为空且 wm 有值时 wm 列金色边框。
- 表头排序：期望价格、白金/十万声望两列的表头可点击，第一次点击按降序，再点恢复默认顺序。批量更新完成后自动按「白金/十万声望」降序排序。
- 上次查询时间带距今天数说明（按自然日，当天显示「今天」）。
- 收益计算 = 各行期望价格之和（已含掉率）；填入单局时间(分钟)和掉落倍率后，可折算白金/分钟和白金/小时。
- 赋能类物品自动按满级（maxRank）筛选卖单，物品名称后显示升满级所需数量（如 ×21个）；MOD和其他物品仍按0级筛选。

## 未入库遗物查询
- 显示当前未入库（可在任务中获取）的遗物，数据来自 relic 文件夹下的官方 wiki ByRelic 页面存档；页面「更新数据」按钮重新解析存档，解析结果缓存到 cache/relics_cache.json。存档更新方式：浏览器打开官方 wiki 该页面，Ctrl+S 保存后覆盖 relic 文件夹中的旧文件。
- 可按纪元筛选（古纪/前纪/中纪/后纪），并显示当前筛选下的遗物数量。
- 掉落物品按稀有度（金/银/铜）分组着色。
- 支持收藏：收藏后整行高亮并置顶，收藏状态保存在浏览器 localStorage。
