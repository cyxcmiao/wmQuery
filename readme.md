# 文件说明：
- auto_install.py：自动检测并安装需要的模块。使用中科大镜像源。
- index.html：查询物品页面。也是网页的首页。
- main.py：程序主文件。
- items_cache.json：程序自动获取的物品名称列表。
- cache文件夹：
  - query_history.json：查询历史记录列表。
  - scene_xxx.json：场景缓存文件。每个场景对应一个文件。

# 使用方式
1. 运行程序后，浏览器打开网址http://127.0.0.1:8899。

# 功能说明
- 自动补全物品名称。程序会自动获取物品名称列表并持久化，24小时内重复获取不会更新列表。
- 查询历史记录。历史记录最多记录10条数据。
- 场景功能。侧边栏可新增、删除场景。鼠标长按侧边栏的场景按钮后可上下拖动场景顺序。
